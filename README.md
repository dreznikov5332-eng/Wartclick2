# WartClick

Клиентский Fabric-мод для Minecraft 1.21.11: автоматический ПКМ мотыгой по созревшей моркови и адскому наросту.

## Режимы

- **По списку** (по умолчанию): записываешь блоки в нужном порядке, мод по очереди наводится на каждый и кликает.
- **Автопоиск**: мод сам ищет зрелые культуры вокруг.

## Клавиши

| Клавиша | Действие |
|---|---|
| B | включить / выключить |
| V | записать блок под прицелом в список |
| Z | удалить последнюю точку |
| X | очистить список (нажать дважды) |
| M | переключить режим |
| N | автопилот вагонетки |

Список хранится в `config/wartclick-points.txt` (координаты абсолютные).

## Сборка

```bash
gradle wrapper --gradle-version 9.8.2   # один раз, чтобы появился ./gradlew
./gradlew build
```

Готовый мод: `build/libs/wartclick-<версия>.jar` (файл без `-sources`).
Нужны Java 21, Fabric Loader и Fabric API.

На GitHub сборка запускается сама (`.github/workflows/build.yml`); при пуше тега `v*` создаётся Release.

Раскладка плоская: `WartClickClient.java` и `fabric.mod.json` лежат в корне (см. `sourceSets` в `build.gradle`).
Workflow сборки: `.github/workflows/build.yml` (текст в `build.yml.txt`).
